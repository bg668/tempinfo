1. 服务概述

本服务位于 EASM 平台与下游系统之间：它从 EASM 获取导出成功的 Excel 报告，完成自动研判并写入本地数据库，然后通过本 API 提供查询能力。

服务负责

轮询 EASM、下载报告、自动研判、数据入库、提供 JSON 查询接口。

下游负责

定期查询已完成报告、分页读取明细、幂等写入自身系统并触发后续处置。

数据边界

API 查询的是本服务已经落库的数据，不会在请求时直接查询 EASM。EASM 已生成报告，不代表本 API 立即可见；还需等待后台完成下载、研判和入库。

“报告概要”与“研判明细”是两个接口

GET /reports/{report_id} 返回报告元数据和数量统计；真正的逐条研判内容必须通过 GET /reports/{report_id}/records 分页获取。

2. 快速接入

2.1 服务地址

默认基础地址为：

http://<服务IP>:8080

例如服务部署在 170 主机、调用程序运行在 177 主机时：

BASE_URL = "http://192.168.1.170:8080"

实际使用时请替换为 170 主机的完整 IP。当前接口路径不包含 /api/v1 前缀。

2.2 网络前提

  • 170 主机上的服务需要监听可被 177 访问的地址，例如 0.0.0.0:8080，不能仅监听 127.0.0.1。
  • 170 主机防火墙或网络 ACL 应允许 177 访问 TCP 8080。
  • 如果服务运行在 Docker 中，需要将容器端口映射到宿主机，例如 8080:8080。

python -m pip install requests

3. 推荐调用流程

检查服务调用 /health，确认 177 可以连接 170。
发现报告查询 completed 报告，取得本地数字 id。
读取概要使用报告 id 获取元数据与数量统计。
分页拉取明细循环增加 offset，直至读取全部记录。
  1. 调用 GET /reports?processing_status=completed，只消费研判完成的数据。
  2. 保存响应中的 id 和 task_id；后续 URL 使用数字 id。
  3. 调用 GET /reports/{id} 获取报告概要。
  4. 调用 GET /reports/{id}/records 分页读取逐条研判结果。
  5. 以下游已消费的 task_id 做幂等，避免重复导入。
不要混用两个 ID

id 是本服务数据库中的数字报告 ID，用于接口路径；task_id 是 EASM 任务 ID，适合用于跨系统关联和下游幂等。

4. 公共约定

4.1 鉴权

除 GET /health 外，所有接口都要求 HTTP Bearer Token。服务端默认从环境变量 DOWNSTREAM_API_TOKEN 读取令牌。

HEADERS = {
    "Authorization": "Bearer <DOWNSTREAM_API_TOKEN>",
    "Accept": "application/json",
}
情况HTTP 状态处理方式
未携带、格式错误或 Token 不匹配401检查 Authorization: Bearer ...，不要盲目重试。
服务端没有配置 Token503由服务维护人员检查部署环境变量或 api.auth_token_env 配置。

4.2 数据格式

  • 请求和响应使用 JSON；POST /admin/poll-now 请求体为空。
  • 时间字段为 ISO 8601 字符串；客户端应按时间解析，不要依赖固定长度或固定时区。
  • 服务增加未知字段时，下游应忽略；枚举出现新值时，下游不应直接解析失败。

4.3 分页

分页接口统一使用 limit 和 offset，响应统一包含：

{
  "items": [],
  "total": 0,
  "limit": 100,
  "offset": 0
}

当累计获取数量达到 total，或者当前页 items 为空时结束分页。

4.4 超时建议

接口类型建议读取超时原因
普通查询接口30 秒只查询本地数据库。
POST /admin/poll-now按单批处理耗时设置，建议数分钟以上该接口会等待本次轮询、下载和研判函数返回。

GET /reports/{report_id}/records Bearer Token

分页查询研判明细

返回报告内的逐条研判记录。结果按 priority_score 降序、记录 id 升序排列；多个过滤条件之间是 AND 关系。

Query 参数

参数类型必填默认值约束说明
limitinteger否1001–1000本页返回条数。
offsetinteger否0≥ 0跳过的记录数。
risk_levelstring否—精确匹配风险级别。
verdictstring否—精确匹配研判结论，对应 triage_verdict。
asset_typestring否—精确匹配资产类型。

Python 请求：分页读取全部明细

def get_all_records(report_id: int) -> list[dict]:
    records = []
    offset = 0
    page_size = 1000

    while True:
        response = requests.get(
            f"{BASE_URL}/reports/{report_id}/records",
            headers=HEADERS,
            params={"limit": page_size, "offset": offset},
            timeout=TIMEOUT,
        )
        response.raise_for_status()
        page = response.json()
        items = page["items"]
        records.extend(items)

        if len(records) >= page["total"] or not items:
            break
        offset += len(items)

    return records

POST /admin/poll-now Bearer Token

立即触发一次轮询

立即从 EASM 查询、下载并处理符合条件的报告。请求体为空，接口会等待本次轮询函数返回。

Python 请求

response = requests.post(
    f"{BASE_URL}/admin/poll-now",
    headers=HEADERS,
    timeout=600,  # 按实际单批处理时间调整
)
response.raise_for_status()
result = response.json()

if result["failed"] > 0:
    print("本次存在处理失败的报告：", result["failed"])

成功响应 · 200

{
  "discovered": 3,
  "processed": 2,
  "failed": 1,
  "skipped": 0,
  "message": null
}
字段类型说明
discoveredinteger本次筛选出的报告数，不等于首次发现数。
processedinteger成功完成下载、研判和入库的报告数。
failedinteger本次处理失败的报告数。

6.3 常见研判枚举

triage_verdict

  • true_positive：高度确认或明确属于真实风险。
  • likely_true：疑似真实风险，建议优先核验。
  • needs_review：信息不足或处于边界，需要人工复核。
  • low_value：价值较低，通常不是优先处置项。
  • false_positive：误报或不构成有效风险。

risk_level

  • critical：严重
  • high：高
  • medium：中
  • low：低
  • info：信息

以上是当前常见值，不应在客户端写成封闭枚举；出现未知值时应保留原值并继续处理。

7. 错误处理

错误通常采用 FastAPI 标准 JSON 格式：

{
  "detail": "report not found"
}
HTTP 状态常见场景下游处理建议
200请求成功读取响应；轮询接口还需检查 failed。
401Token 缺失或错误检查鉴权配置，不要自动高频重试。
404report_id 不存在重新查询报告列表，确认使用的是本地数字 id。
422参数类型或范围错误检查 limit、offset 和 report_id。
503服务端没有配置下游 Token联系服务维护人员检查部署配置。
500服务内部异常记录请求时间、路径和响应内容，联系维护人员。

Python 统一错误处理

import requests

try:
    response = requests.get(
        f"{BASE_URL}/reports",
        headers=HEADERS,
        params={"processing_status": "completed"},
        timeout=TIMEOUT,
    )
    response.raise_for_status()
    data = response.json()
except requests.Timeout:
    print("请求超时")
except requests.ConnectionError as exc:
    print("无法连接 170 服务：", exc)
except requests.HTTPError as exc:
    print("HTTP 请求失败：", exc.response.status_code, exc.response.text)
except ValueError:
    print("服务返回的内容不是合法 JSON")

8. 同步与幂等建议

8.1 只消费已完成报告

下游定期查询 processing_status=completed，并以 task_id 判断是否已处理。不要只依赖分页位置：新报告插入列表头部后，固定 offset 可能发生分页漂移。

8.2 推荐幂等键

对象推荐键用途
报告task_id跨 EASM、本服务和下游系统稳定关联。
研判记录report_id + record.id避免同一报告的明细重复写入。

8.3 失败报告

response = requests.get(
    f"{BASE_URL}/reports",
    headers=HEADERS,
    params={"processing_status": "failed", "limit": 100, "offset": 0},
    timeout=TIMEOUT,
)
response.raise_for_status()

for report in response.json()["items"]:
    print(report["task_id"], report["processing_error"])

下游不应直接修改 SQLite 触发重试。若服务端启用 retry_failed: true，后台会按配置重试；维护人员也可以调用 POST /admin/poll-now。

HEADERS = {
    "Authorization": f"Bearer {TOKEN}",
    "Accept": "application/json",
}
TIMEOUT = 30


def get_json(path: str, params: dict | None = None) -> dict:
    response = requests.get(
        f"{BASE_URL.rstrip('/')}{path}",
        headers=HEADERS,
        params=params,
        timeout=TIMEOUT,
    )
    response.raise_for_status()
    return response.json()


def get_all_records(report_id: int) -> list[dict]:
    records = []
    offset = 0
    page_size = 1000

    while True:
        page = get_json(
            f"/reports/{report_id}/records",
            {"limit": page_size, "offset": offset},
        )
        items = page["items"]
        records.extend(items)
        print(f"已获取 {len(records)} / {page['total']} 条研判记录")

        if len(records) >= page["total"] or not items:
            return records
        offset += len(items)


def main() -> None:
    # /health 不需要鉴权
    health_response = requests.get(f"{BASE_URL}/health", timeout=TIMEOUT)
    health_response.raise_for_status()
    print("服务状态：", health_response.json())

    report_page = get_json(
        "/reports",
        {"processing_status": "completed", "limit": 1, "offset": 0},
    )
    if not report_page["items"]:
        print("当前没有处理完成的报告")
        return

    latest = report_page["items"][0]
    report_id = latest["id"]

    report = get_json(f"/reports/{report_id}")
    stats = get_json(f"/reports/{report_id}/stats")
    records = get_all_records(report_id)

    result = {
        "report": report,
        "stats": stats,
        "records": records,
    }
    output = Path(f"report_{report_id}.json")
    output.write_text(
        json.dumps(result, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    print("报告已保存：", output.resolve())


if __name__ == "__main__":
    try:
        main()
    except requests.RequestException as exc:
        raise SystemExit(f"API 请求失败：{exc}")

10. 安全建议与当前限制

10.1 安全建议

  • API 只通过内网或 HTTPS 暴露，不要把 8080 端口直接开放到公网。
  • 为下游 API 使用独立 Token，并定期轮换；不要把 Token 写入 Git、URL 参数或日志。
  • 限制 /admin/poll-now 的调用来源，只允许运维或调度系统访问。
  • 不要让 177 直接读取 170 的 SQLite、raw 或 processed 目录。
  • 优先使用研判后的字段，避免扩大原始敏感信息的传播范围。

10.2 当前版本限制

  • 只提供 JSON 查询和立即轮询，不提供原始 Excel 下载接口。
  • 数据库适配器当前只支持 SQLite。
  • 过滤条件只支持精确匹配，不支持模糊查询、时间范围和风险等级比较。
  • 分页方式为 limit + offset；持续写入期间需要结合 task_id 做幂等。
  • /health 只表示 HTTP 服务可响应，不代表后台任务和模型处理正常。
